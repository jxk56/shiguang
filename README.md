# 诗光 · 中小学古诗词学习馆

按年级浏览统编语文教材既有目录，支持原文、逐字拼音、注释、原创诗意概要与赏析、遮字背诵、浏览器朗读、原创练习、错题本、收藏和背诵进度。

## 本地使用

直接用浏览器打开 `dist/index.html` 即可。网站没有构建步骤，不依赖外部字体、CDN或在线服务。朗读依赖系统中文语音；学习记录保存在当前浏览器，可在「我的学习」导出和合并导入。

## 文件

- `dist/index.html`、`dist/style.css`、`dist/app.js`：网页与交互。
- `dist/data.js`：随网页加载的内容数据。
- `dist/poetry-data.json`：可编辑、可迁移的诗词与原创题库。
- `.openai/hosting.json`：Sites项目标识和静态目录。

## 收录范围

以小学、初中既有统编教材目录及2019版高中五册为基线。小学保留112条教材归属记录，初中收录古代85篇并额外保留2条现代诗词索引，高中收录古代诗词与《游园》选段。重复教学篇目按年级分别记录。高中年级仅为建议学习顺序，教材册次才是准确课程归属。

小学和初中2024修订版尚未完成逐册逐页校验，不能宣称覆盖2026所有印次与地区。每篇有参考来源，诗句采用公版古诗文本；现代作者作品仅提供短摘录/索引和原创学习概要。长篇节选会在题名或说明中标记。

注释、白话概要、赏析与题目为原创学习内容。练习并非教材课后原题或考试真题。表达题为对照参考答案自评，选择题和默写题自动判分。

拼音通过pinyin-pro生成并作常见古诗多音字校正，仍须以所用教材及老师教学要求为准。浏览器语音引擎不一定遵从网页注音。
