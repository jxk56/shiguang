# 诗光 · 中小学古诗文学习馆

按年级、学制和教材册次学习古诗词与文言文。支持原文拼音、关键词注释、逐句及全文白话译文、理解赏析、遮字背诵、朗读、原创练习、错题本和学习记录。

公开网站：https://shiguang-school-poetry.xtc49321.chatgpt.site/

## 本地阅读

用浏览器打开 dist/index.html 即可。页面无构建步骤，也不依赖外部字体或 CDN。收藏、背诵状态和错题保存在各自浏览器内，可在“我的学习”导出或合并导入。朗读使用系统中文语音。

## 文件

- dist/index.html、dist/style.css、dist/app.js：页面与交互。
- dist/data.js：页面加载的数据。
- dist/poetry-data.json：完整古诗文、释义、题目和教材归属数据。
- .openai/hosting.json：既有 Sites 项目标识与静态目录。

## 内容与教材范围

保留既有诗词索引，新增统编小学、初中、高中必修与选择性必修的文言课文、教材节选及蒙学篇目。山东六三制、五四制分别标注，五四制六年级支持既有版与2024修订版筛选。旧版篇目与不同选段独立标识；高中年级为建议学习顺序，以教材册次及学校进度为准。

本次依据既有目录及已核对的修订差异整理，具体印次请对照实际使用教材。各篇详情提供原文和教材目录来源；长篇节选标记收录范围。古代及已进入公版的作品提供原文，现代诗词继续提供现有短摘录或索引。

注释、逐句与全文白话译文、赏析及题目由本站整理编写。练习不照录教材课后题或考试真题。选择题、默写题自动判分；翻译及理解题对照参考答案自评。

拼音通过 pinyin-pro 生成，并校正古文通假、多音字和人名；扩展汉字按 Unicode 码点对齐。浏览器语音引擎可能不采用页面显示的读音。
